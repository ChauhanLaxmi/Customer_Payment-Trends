# Customer_Payment-Trends
This project contains SQL scripts to analyze customer orders and payment data.
The goal is to extract insights such as order trends, payment statuses, customer activity, and more using structured SQL queries.

🧠 Query Highlights
🔹 Customer Orders Analysis
🔹Total Order Amount
🔹Successfully Delivered Orders
🔹Unique Customers and Order Status
🔹Orders by Weekday and Month

🧠 Payments Analysis
🔹Total Payment Value
🔹Payment Methods and Status
🔹Year with Highest Payments
🔹Customers with Failed or Completed Payments

🧠 Visuals include KPIs such as:
🔹Total Orders & Payments
🔹Orders by Day/Month
🔹Payment Status & Method
🔹Customer Insights
